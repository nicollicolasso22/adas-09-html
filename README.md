## Exercícios

### [Tela de compra de tickets](Exercicio.md)

Um parque de diversões vai vender ingressos pela internet. Cada ingresso é comprado por um responsável para uma criança, com pagamento no cartão de crédito. O exercício é montar o formulário de compra em HTML, usando o tipo de `input` certo para cada campo e as validações nativas do HTML, e mostrar o valor total de **R$ 103,97**.
